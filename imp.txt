KNOWBRIDGE — ANTIGRAVITY PROJECT INSTRUCTIONS

PROJECT
KNOWBRIDGE is an AI-powered knowledge continuity and handover platform. It helps organizations preserve project decisions, technical context, ownership, dependencies, blockers, and workflows when people change roles or leave.

CORE WORKFLOW
CONNECT authorized information sources → RECONSTRUCT project knowledge → VERIFY claims against source evidence → REVIEW with authorized humans → HANDOVER through role-specific reports.

TECHNOLOGY DIRECTION
- Frontend: Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, TanStack Query, React Flow, and Recharts.
- Backend: Python, FastAPI, Pydantic, SQLAlchemy 2.0, Alembic, and versioned REST APIs under /api/v1.
- AI: provider abstraction, LangGraph where useful, Sentence Transformers, RAG, pgvector, and document parsing with Docling or Unstructured.
- Infrastructure: PostgreSQL, Redis, Celery, S3-compatible object storage, Docker, GitHub Actions, and an AWS deployment path.
- Security: JWT access and refresh tokens, RBAC, organization-level tenant isolation, OAuth 2.0 integrations, audit logs, and secure document access.

ARCHITECTURAL PRINCIPLES
- Begin as a modular monolith. Keep domain modules independent and communicate through explicit service interfaces so modules can later be extracted.
- Separate API request handling from background AI, ingestion, and document-processing work.
- Enforce tenant and project authorization in backend services and data access; frontend filtering is never an authorization boundary.
- Treat imported documents and connector content as untrusted input.
- Preserve source revisions and evidence provenance. Important claims must link to source evidence and remain reviewable by authorized people.
- Keep secrets in environment configuration or an appropriate secret store. Never hardcode credentials or API keys.
- Do not substitute fake data for working behavior or claim a feature is complete without implementation and verification.
